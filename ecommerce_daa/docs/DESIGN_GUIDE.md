# Design guide
`Plan` contains a fixed-capacity order array and undirected weighted road adjacency matrix. `optimizer.h` declares consistent function interfaces. Shortest path: Dijkstra and Bellman-Ford compute distance from depot 0; both are exact for nonnegative road costs. Sorting: Merge Sort and Quick Sort sort by descending priority, then ascending ID. Capacity: greedy chooses highest value/weight ratio, while 0/1 knapsack dynamic programming maximizes total selected value. The report compares both on the same input. Benchmark datasets are generated deterministically. Limits: 160 locations, 1200 orders, 6000 capacity units. No persistent order database, multi-vehicle scheduling, or joint route/capacity optimization.
